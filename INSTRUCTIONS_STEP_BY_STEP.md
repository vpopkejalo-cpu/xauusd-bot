## 🟢 ШАГ 3. Размещаем код на GitHub (2 минуты)

Облако Render умеет автоматически запускать ботов прямо из личного репозитория GitHub.

1. Откройте в браузере сайт: **[https://github.com](https://github.com)**
2. Зарегистрируйтесь (если еще нет аккаунта) или войдите под своим логином.
3. В правом верхнем углу нажмите на значок **`+`** и выберите **«New repository»** (Новый репозиторий).
4. Заполните всего 2 поля:
   - **Repository name (Имя):** напишите `xauusd-bot`
   - Переключатель: оставьте **`Public`** (или `Private`, Render поддерживает оба варианта).
   - *Галочки «Add README» или «Add .gitignore» ставить НЕ нужно, у нас всё уже создано!*
5. В самом низу нажмите зеленую кнопку **«Create repository»**.
6. GitHub покажет страницу со ссылкой на ваш репозиторий вида:
   ```text
   https://github.com/ВАШ_ЛОГИН/xauusd-bot.git
   ```

### 💻 Теперь привязываем код с вашего Mac:
1. На вашем Mac нажмите комбинацию клавиш `Command (⌘) + Пробел` (Spotlight).
2. Наберите слово **Терминал** (Terminal) и нажмите `Enter`.
3. Скопируйте и вставьте по очереди следующие 3 команды (заменив `ВАШ_ЛОГИН` на ваш логин на GitHub):

```bash
cd "/Users/VN0039/Агент трейдинга"
git remote add origin https://github.com/ВАШ_ЛОГИН/xauusd-bot.git
git push -u origin main
```
*(При первом запросе терминал может попросить ввести логин GitHub и пароль/токен).*

## 🟢 ШАГ 4. Запускаем бота на Render.com (Без карты!)

1. Откройте сайт: **[https://render.com](https://render.com)**
2. В правом верхнем углу нажмите **«Sign Up»** (Регистрация).
3. Нажмите кнопку **«Sign in with GitHub»** (Войти через GitHub) — так аккаунты свяжутся автоматически в 1 клик.
4. После входа в панель управления Render нажмите синюю кнопку **«+ New»** (в правом верхнем углу) и выберите **«Web Service»**.
5. В списке репозиториев найдите ваш **`xauusd-bot`** и нажмите кнопку **«Connect»** напротив него.
6. На открывшейся странице настроек проверьте/заполните поля:
   - **Name:** `xauusd-bot`
   - **Region:** выберите `Frankfurt (EU Central)` или `Oregon (US West)`
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Instance Type:** убедитесь, что выбран **Free ($0/month)**.

### 🔑 Вставляем ваши 3 ключа:
Прокрутите страницу чуть ниже до раздела **«Environment Variables»** (Переменные окружения). Нажмите **«Add Environment Variable»** и добавьте 3 строки:

| Key (Название) | Value (Значение) |
| :--- | :--- |
| `TWELVE_DATA_API_KEY` | *(Вставьте ваш ключ с Twelve Data из Шага 2)* |
| `TELEGRAM_BOT_TOKEN` | *(Вставьте токен вашего бота из @BotFather)* |
| `TELEGRAM_CHAT_ID` | *(Вставьте ваш цифровой ID из @userinfobot)* |

7. В самом низу страницы нажмите синюю кнопку **«Deploy Web Service»** (Создать сервис).

Через 1-2 минуты Render установит библиотеки и запустит бота.  
**В ту же секунду в ваш Telegram придет приветственное сообщение от бота! 🚀**

## 🟢 ШАГ 5. Настраиваем вечную работу 24/7 (1 минута)

На бесплатном тарифе Render служба может "засыпать", если к ней никто не обращается больше 15 минут.  
Но мы уже встроили в вашего бота встроенный веб-сервер проверки здоровья (`Health Check`)! 

Чтобы бот **никогда не засыпал и работал 24 часа в сутки 7 дней в неделю**:
1. На странице вашего сервиса на Render скопируйте его адрес (он находится вверху под названием, например: `https://xauusd-bot.onrender.com`).
2. Откройте бесплатный сервис автоматических пингов: **[https://cron-job.org](https://cron-job.org)**
3. Нажмите **Sign Up** (бесплатная регистрация за 30 секунд по email, без карты).
4. Перейдите во вкладку **Cronjobs** → нажмите **«Create Cronjob»**.
5. Заполните:
   - **Title:** `Keep Gold Bot Alive`
   - **URL:** вставьте скопированную ссылку на ваш бот (например: `https://xauusd-bot.onrender.com`)
   - **Schedule:** выберите **Every 10 minutes** (каждые 10 минут).
6. Нажмите **Create**.

🎉 **ВСЁ ГОТОВО!**  
Сервис cron-job.org будет раз в 10 минут отправлять легкий сигнал боту, подтверждая, что система активна.  
Бот будет непрерывно анализировать рынок золота, переобучаться и присылать вам торговые сигналы в Telegram 24/7!
