# 🏆 Автономный Telegram-помощник трейдера (XAU/USD)

Полностью автономная система на Python для круглосуточного (24/7) анализа рынка золота (**XAU/USD**) с предиктивным машинным обучением (**Machine Learning**), динамическим риск-менеджментом на основе **ATR** и доставкой готовых торговых сигналов в **Telegram**.

Разработано специально для пожизненно бесплатного тарифа **Google Cloud Platform (e2-micro)** с автоматическим перезапуском через **systemd**.

---

## 🌟 Ключевые возможности

1. **24/7 Автономная работа в облаке:**
   - Развертывание на бесплатном сервере Google Cloud `e2-micro`.
   - Фоновая служба `systemd` с директивой `Restart=on-failure` — автоперезапуск при перезагрузках или сетевых сбоях.
   - Автоматическая настройка 2GB SWAP-файла для предотвращения OOM (нехватки оперативной памяти).

2. **Поставщик рыночных данных (Twelve Data API):**
   - Строгое соблюдение лимитов бесплатного тарифа (800 запросов/сутки, 8 запросов/мин).
   - Экспоненциальная задержка при лимитах (HTTP 429) через библиотеку `tenacity`.
   - Локальное кэширование свечей в SQLite базе данных.

3. **Машинное обучение (Machine Learning & Self-learning):**
   - Предобработка признаков через `pandas_ta` (RSI 14, EMA 9/21/50, ATR, MACD, моментум движения).
   - Модель `LogisticRegression` со `StandardScaler` (`scikit-learn`).
   - Защитный фильтр вероятности: сигнал отправляется **только при уверенности модели $P \ge 60\%$**.
   - **Автоматическое периодическое самообучение:** каждые 24 часа модель пересчитывает веса на свежих рыночных данных и сохраняет обновленную версию.

4. **Фильтр микроструктуры рынка (Азиатская сессия):**
   - Блокировка сигналов в период с **23:00 до 08:00 GMT** (время низкой ликвидности в Азии, предшествующее ложным выносам перед Лондоном).
   - Автоматическое определение выходных дней (закрытие рынка Forex/Gold с вечера пятницы до вечера воскресенья).

5. **Динамический риск-менеджмент:**
   - Расчет Take Profit (TP) и Stop Loss (SL) в реальном времени от текущей волатильности `ATR(14)`.
   - SL = $1.5 \times ATR$, TP = $2.5 \times ATR$ (соотношение риск/прибыль $1:1.67$).

6. **Telegram Bot API:**
   - Прямые REST API POST-запросы к методу `sendMessage`.
   - Премиальная HTML-разметка с эмодзи, ценой входа, уровнями TP/SL, уверенностью модели и сессией.
   - Оповещения о закрытии сделок по TP/SL и сеансах самообучения модели.

## ⚡ Быстрый запуск на сервере в 1 команду

На чистом сервере Google Cloud выполните:

```bash
git clone <URL_РЕПОЗИТОРИЯ> ~/xauusd_bot && cd ~/xauusd_bot && chmod +x setup.sh && ./setup.sh
```

Инсталлятор сам:
1. Создаст 2GB SWAP памяти.
2. Установит Python 3, venv, зависимости из `requirements.txt`.
3. Запросит ваши ключи API и создаст `.env`.
4. Настроит службу `systemd` и запустит бота круглосуточно в фоне.
5. Пришлет в Telegram подтверждение о старте!

## 🛠 Полезные команды управления

| Действие | Команда |
| :--- | :--- |
| **Проверить статус работы** | `sudo systemctl status xauusd_bot` |
| **Смотреть журнал (логи) в реальном времени** | `sudo journalctl -u xauusd_bot -f` |
| **Перезапустить бота** | `sudo systemctl restart xauusd_bot` |
| **Остановить бота** | `sudo systemctl stop xauusd_bot` |
